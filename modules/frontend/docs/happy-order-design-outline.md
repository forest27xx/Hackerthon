# plan

## 结论摘要

“快乐下单事务所”是一个 Web 仿小程序的吃喝玩乐下单游戏。它保留奶茶/外卖小程序的下单爽感，但把普通交易扩展成“状态选择、策略点单、配送事件博弈、食品安全/健康知识、结果卡分享”的完整 demo。

第一版已经按纯前端实现：React + Vite + TypeScript、本地数据驱动、图片按商品名自动映射、规则模板生成小票和结果卡。

## 核心体验

1. 用户先选择今日状态：困、馋、emo、加班、摸鱼、庆祝、约会、发疯、健身后、深夜嘴馋。
2. 进入仿小程序点单界面：左侧分类、右侧商品、规格加料、底部购物车。
3. 商品不只计算价格，还计算快乐值、健康值、饱腹值、清醒值、安全值。
4. 商品标签和用户状态会触发 combo，例如“加班续命包”“低糖自律局”“周五发疯套餐”“深夜罪恶但有分寸”。
5. 确认下单后进入配送事件小游戏，每次随机抽取 3-5 个事件。
6. 事件选择影响速度、安全、健康、完整度、信任值。
7. 最终生成“快乐订单小票”和“今日快乐结果卡”，支持保存 PNG 和复制分享文案。

图片策略：

- 团队把图片统一放进 `src/assets/menu/`。
- 图片文件名直接等于商品名，例如 `杨枝甘露.webp`。
- 程序会自动匹配图片；找不到时使用分类兜底图。
- 后续如果图片名和商品名不一致，可以在商品数据里补 `imageKey`。

## 配送事件小游戏

配送过程不是等待页，而是一个“安全、健康、沟通、包装”的选择游戏。

事件类型共 6 类：

| 类型 | 设计目标 | 示例事件 |
| --- | --- | --- |
| 商家食品安全 | 把食品安全知识变成选择 | 封口机故障、冷热分袋、小料刚煮好、备注被忽略 |
| 骑手安全 | 引导用户理解安全配送 | 暴雨配送、抄近路、门禁复杂、高温配送 |
| 防撒漏包装 | 让餐品完整度可被玩家影响 | 汤粉奶茶同袋、电梯拥堵、路线颠簸、多杯拿错 |
| 健康生活 | 把饮食和运动建议轻量游戏化 | 深夜高糖、高油高盐、饭后久坐、健身后补给 |
| 用户备注博弈 | 模拟真实备注沟通 | 备注太长、想快又想稳、健康和加料冲突、催单措辞 |
| 趣味突发 | 增加随机性和传播感 | 优惠券诱惑、朋友拼单、新品试喝、订单命名失败 |

知识点底层参考：

- 食品安全：WHO 食品安全五要点，包括保持清洁、生熟分开、彻底煮熟、安全温度、安全水和原料。
- 健康饮食：CDC 健康饮食建议，包括减少添加糖、减少钠、增加膳食纤维和食物多样性。
- 运动生活：WHO 身体活动指南，只做轻量生活提示，不做医疗建议。

## 结果生成

最终输出两种模板：

1. 快乐订单小票
   - 风格：热敏小票、虚线、订单摘要、combo 章。
   - 内容：商品列表、订单金额、触发组合、配送博弈摘要、快乐/健康/安全指数。

2. 今日快乐结果卡
   - 风格：竖版手机海报，适合截图和分享。
   - 内容：订单标题、今日人格、三项指数、下一单建议。
   - 技术：使用 `html-to-image` 导出 PNG。
