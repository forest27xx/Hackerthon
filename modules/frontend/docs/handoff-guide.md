# EATI 前端交接指南

更新时间：2026-05-30

## 1. 项目一句话

`EATI / 今天你吃商几级？` 是一个黑客松外卖点单小游戏 demo。用户先选择今日下单动机，再像在美团、饿了么、京东外卖里一样点餐、用券、选择套餐，之后进入外卖配送过程中的选择题，最后生成“吃商等级 + 真实 MBTI 吃商人格”结果卡。

当前实现是纯前端本地 demo，不依赖后端和数据库。

## 4. 演示流程

建议现场按这个顺序演示：

1. 首页选择一个状态，例如 `加班`。
2. 进入点单页，看顶部状态条、吃商钱包、神券膨胀、吃商线索套餐。
3. 点击 `神券膨胀`，让某张优惠券随机增加 3-10 元优惠。
4. 点击 `加班幸运包` 或其他推荐套餐，一键加入购物车。
5. 展开购物车，展示红包券、已点菜品图片、数量调整。
6. 在购物车内部上下滑动，说明内部滚动不会误收起；在外部下滑会自动收起。
7. 点击 `下单`，进入“订单进行中”沉浸式场景页。
8. 完成 8 个商家/骑手/收餐节点，说明题目来自自适应题库，不会出现与本单无关的问题。
9. 先展示烫金订单小票，再展示 16 型吃商人格分析卡、保存 PNG 和复制分享文案功能。

## 5. 已实现功能

### 点单与商品

- 已有 10 个分类：奶茶、咖啡、甜品、小吃、夜宵、轻食、主食、炒菜、汤锅、其他。
- 商品数量约 150 个，图片按商品名自动映射。
- 商品标签已汉化，例如 `咖啡因`、`低糖`、`高蛋白`、`适合分享`。
- 不同菜品有不同规格项，例如甜度、冰量、分量、加料、包装、健康备注。

### 钱包和优惠券

- 吃商钱包额度：150 元。
- 优惠券规则：满 39 减 5、满 59 减 10、满 89 减 18、满 129 减 28。
- 优惠券放在购物车抽屉顶部，红色红包样式，可折叠展开。
- `神券膨胀` 会随机选择当前目标券增加 3-10 元优惠，一次只膨胀一张券。

### 套餐预设

- 根据今日吃商线索推荐套餐。
- 例如：加班幸运包、低碳自律局、周五放纵套餐、深夜回血包、约会不翻车、干饭安心包。
- 点击套餐可以把整份组合直接加入购物车。
- 套餐展示菜品小图、组合文案和券后价格。

### 购物车交互

- 底部购物车栏已压缩，避免遮挡抽屉。
- 底部只显示：实付价、券减金额、钱包剩余、快乐/健康/安全三项指标、下单按钮。
- 不再显示 `事务所订单` 和 `x 件` 文案。
- 购物车内部滚动不会自动收起；抽屉外区域下滑才会收起。

### 订单进行中与结果

- 下单后进入“订单进行中”场景页，用户始终是下单人视角。
- 每局固定 8 个节点，背后从 100 条题库里按商品分类、标签、目的和订单结构过滤抽取。
- 事件覆盖商家规格/缺货/包装、骑手沟通/路况/门禁、收餐确认等真实选择。
- 最终先生成烫金订单小票，再生成 16 型真实 MBTI 吃商人格结果。
- 支持保存结果 PNG 和复制分享文案。

## 7. 改内容时怎么下手

### 加新菜品

编辑：

```text
modules/frontend/src/data/catalog.ts
```

每个商品至少要有：

```ts
{
  id: "unique-id",
  name: "商品名",
  category: "staple",
  price: 28,
  description: "一句能激发购买欲的描述。",
  tags: ["fullness", "safe"],
  stats: { joy: 8, health: 2, fullness: 12, energy: 0, safety: 4 }
}
```

图片命名尽量等于商品名，例如：

```text
modules/frontend/src/assets/menu/黑椒牛柳意面.webp
```

### 改优惠券

编辑 `src/App.tsx` 里的 `coupons`：

```ts
const coupons = [
  { id: "c39", label: "满39减5", threshold: 39, discount: 5, description: "轻量可用" }
];
```

`threshold` 是门槛，`discount` 是减免金额。

### 改套餐

编辑 `src/App.tsx` 里的 `mealPresets`：

```ts
{
  id: "work-luck",
  name: "加班幸运包",
  line: "咖啡 + 主食 + 蛋白",
  moods: ["overtime", "tired"],
  tags: ["caffeine", "fullness", "protein"],
  itemNames: ["冰美式续命杯", "黑椒牛柳意面", "卤味溏心蛋"]
}
```

注意：`itemNames` 必须和 `catalog.ts` 中的商品名一致，否则套餐里找不到对应菜品。

### 改配送选择题

编辑 `src/data/catalog.ts` 中的 `deliveryEvents`。每个事件建议包含：

- `title`：题目名
- `description`：场景描述
- `knowledge`：轻量知识点
- `choices`：2-3 个选项
- 每个选项对应的分数变化

### 改结果人格

编辑：

```text
src/lib/gameEngine.ts
```

重点看人格轴和 `generateResultSummary` 相关逻辑。

## 8. 当前注意事项

- 这是纯前端 demo，没有登录、支付、后端订单系统。
- 钱包和优惠券只做演示逻辑，不做真实支付。
- 图片素材可以直接替换，但文件名最好与商品名一致。
- 不建议大改目录结构；当前结构已经能稳定演示。
- 每次提交前至少跑：

```bash
npm test -- --run
npm run build
```
